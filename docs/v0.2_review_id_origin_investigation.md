## 4. Root Cause Analysis

Both errors share a common pattern:

1. The batch_002 input (`batch_002.jsonl`) was constructed with record IDs whose **subcategory segments** do not match the actual ID strings stored in the curated dataset and manifest.
2. The **content and decisions** (approved, reviewer_id, reason text) correctly reference the real underlying records — only the ID strings are wrong.
3. This is a **generation/construction error** in the batch input pipeline, not a data-loss or scope-inclusion error.

Possible sources of the error:
- The batch-generation script derived the subcategory from a secondary metadata field instead of reading the canonical ID from the curated data.
- A field mapping swap occurred during batch input assembly (e.g., `subcategory` field was read from a different data view).
