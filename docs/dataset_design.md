# Dataset Design

## 1. Philosophy

Atlas exists to outlive any single model. The design enforces **separation of
concerns** between data and presentation:

- **Storage format** = canonical JSONL (model-agnostic).
- **Presentation format** = generated on demand by converters.

This means a future 8B-class model with a novel template needs **zero data
migration** — only a new entry in `configs/formatting/templates.json`.

## 2. Layered Stages

| Layer | Path | Mutability | Purpose |
|---|---|---|---|
| Raw | `raw/` | immutable | original sources, preserved forever |
| Processed | `processing/` outputs (tmp/) | regenerable | cleaned/deduped intermediate |
| Curated | `curated/vX.Y/` | versioned, append-only | reviewed, release-ready |
| Training | generated by converters | disposable | model-specific, never source of truth |

## 3. Record Identity

- `id` is globally unique and stable: `<category>_<subcategory>_<seq>`.
- Two records with identical content but different provenance get **different
  ids** (provenance matters for licensing and review).
- Deduplication operates on normalized content, not id.

## 4. Category Taxonomy

Nine top-level categories (`metadata/categories.json`), each with controlled
subcategories. Category balance target for v0.1 is defined in
`metadata/dataset_card.md`. Balance is enforced by `validate_dataset.py --stats`.

## 5. Message Contract

- `messages` is an ordered array; `role` ∈ {system, user, assistant, tool}.
- System prompt is optional but recommended for steering.
- Multi-turn conversations are allowed (type=`conversation`).
- `tool` role is reserved for future function-calling datasets.

## 6. Metadata Per Item

Every record carries full provenance (`source`), discoverability (`tags`),
a numeric `quality_score`, and a boolean `verified` gate. This makes the
dataset **auditable** — critical for a long-lived foundation.

## 7. Reproducibility

- All transforms are scripts under `scripts/` + `processing/`.
- Randomness (splits, sampling) must be seeded and logged.
- Release manifests record exact input hashes → output hashes.

## 8. Expansion Strategy

1. Ingest raw → `raw/`
2. Clean → `tmp/`
3. Dedup + validate + score
4. Human review → `verified=true`
5. Promote to `curated/vX.Y/`
6. Cut a versioned release with manifest + stats

Bulk ingestion is gated on human approval to protect quality.
