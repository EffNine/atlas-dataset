### 2.1 Definition of an Exact Match

### 2.2 Confidence Levels

Once a candidate is found, assign a confidence level:

| Level | Criteria | Action |
|-------|----------|--------|
| **High** | Exact character-for-character match of the canonical answer in a single answer post | Use as authoritative source |
| **Medium** | Very similar text — same concepts, same structure — but minor phrasing differences | Accept as source; note minor divergence in `modifications` field |
| **Low** | Similar concepts but substantially different wording | Likely not the source; continue searching |
| **No match** | No candidate found on Stack Overflow or Unix & Linux | Fall back to generic attribution via the data dump URL |

## 4. Validation Checklist

Use this checklist to validate the human-supplied source data before recording it.

- [ ] `attribution_text` follows the template: work title + author + URL + license

- [ ] `modifications` field honestly describes whether content was adapted
- [ ] If adapted, the nature of the changes is stated honestly
- [ ] If unknown, it says so

#### Lineage Verification

- [ ] `parent_lineage` matches `source_attribution.url`
- [ ] `acquisition_origin` is populated (or honestly states unknown)

| # | Obligation | Met? | Evidence |
