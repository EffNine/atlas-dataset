# Hermes Project Ideas & Vision

## Project Identity

Hermes is a long-term AI experimentation and engineering ecosystem.

The purpose of Hermes is not to create one AI model.

The purpose is to build a system where:

* knowledge can be collected
* datasets can be curated
* models can be improved
* agents can be created
* workflows can be automated

Hermes should evolve together with AI technology.

---

The dataset should not belong to one model.

It should support:

* future models

# Development Rules

## Start Small

Do not build everything at once.

Priority:

1. Dataset foundation
2. Memory system
3. Model experiments
4. Agent framework
5. Automation

---

## Document Everything

Every important decision should have:

* reason
* alternatives considered
* result
* lessons learned

---

## Preserve Knowledge

Temporary experiments should become permanent knowledge.

Successful experiments become:

* documentation
* datasets
* reusable tools
